# Vylo 項目表（文件/資料夾依賴與用途）

> 最後更新：2026-10-26

## 資料夾結構

| 路徑 | 用途 | 依賴 |
|------|------|------|
| `cmd/server/` | 執行入口 `main.go`：config.Load → vylo.New → cache.New → server.New → ListenAndServe；含 `shortenerAdapter`（cache→server 介面轉接） | config, vylo, cache, server, web |
| `internal/config/` | 讀環境變數（VYLO_API_TOKEN 必填、BASE_URL/STEPS/TARGET_URL/PORT 有預設） | 僅標準庫 |
| `internal/vylo/` | Vylo API client：`Shorten(ctx, url, steps)`；JSON 解析、`vylo: ` 前綴錯誤、429/網路錯誤指數退避重試×3 | 僅標準庫 |
| `internal/cache/` | 記憶體快取 `GetOrShorten`：key=(steps\|longURL)、TTL 12h、RWMutex、錯誤不快取、可注入時鐘 | 定義 `Shortener` 介面（由 vylo client 實作） |
| `internal/server/` | HTTP 路由：`GET /{$}`、`/go`（302 短鏈/失敗 fallback TARGET_URL，no-store）、`/thanks`、`/healthz`、`/favicon.svg`、`/favicon.ico`、`/icon.png`、`/og.png`、`/robots.txt`；405/404 處理；`securityHeaders` 中介層（nosniff/DENY/no-referrer/CSP）；介面注入 Shortener + fs.FS | 定義自己的 `Shortener` 介面 + `Config` |
| `web/` | `index.html`（首頁大按鈕）+ `thanks.html`（感謝頁）+ `web.go`（`//go:embed` 包成 `web.FS`）+ 靜態資產 `favicon.svg`、`icon.png`（180×180，兼作 /favicon.ico）、`og.png`（1200×630 分享預覽圖）、`robots.txt`；純 HTML/CSS 零外部依賴、繁中介面、description+OG+Twitter meta、prefers-reduced-motion 支援 | 僅標準庫 embed |
| `.github/workflows/` | `ci.yml`（vet+test -race+build，push main/PR）；`docker.yml`（buildx 多平台推 ghcr.io/s12ryt/vylo，push main/tag v*/PR） | 僅 GitHub Actions |
| `Dockerfile` + `.dockerignore` | multi-stage 建置（golang:1.26-alpine → alpine:3.20）；非 root UID 10001；HEALTHCHECK | 無（獨立建置定義） |
| `agent/` | 開發記錄：question.md（需求/TDD 驗收標準）、項目表.md（本檔）、memory.md、deep_todos.md | — |

## 依賴方向（箭頭 = import）

```
cmd/server ──► internal/server ◄── e2e_test（server_test 包）
    │              │
    │              └─(介面)─ 由 cmd/server 的 adapter 滿足
    ▼
internal/config   internal/vylo ──► (實作 cache.Shortener 介面)
    ▲                  │
    └── cmd/server     ▼
              internal/cache ──► (依賴注入 Shortener=vylo client)
web.FS ──► cmd/server / e2e_test（注入 server.Config.Static）
```

## 關鍵介面

- `cache.Shortener` / `server.Shortener`：`Shorten(ctx, longURL, steps) (string, error)`——兩處各自定義（介面隔離），vylo client 與 cache 分別滿足
- `server.Config.Static fs.FS`：測試注入 `fstest.MapFS`，正式注入 `web.FS`
